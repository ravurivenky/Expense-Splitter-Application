# 💰 Expense Splitter Application

A simple and user-friendly Expense Splitter application designed to manage shared expenses, track payments, and simplify the process of splitting bills among friends, family, or groups.

The application helps users record expenses, calculate individual contributions, and understand who owes whom.

## 🚀 Features

### 👥 User Management
- Add and manage users.
- Maintain user details.
- Associate expenses with individual users.

### 💸 Expense Management
- Add new expenses.
- Track expense descriptions and amounts.
- Associate expenses with users who paid.
- View expense details.

### 🧮 Expense Splitting
- Calculate shared expenses.
- Simplify expense settlements.
- Identify who owes money and who should receive money.

### 📥 Import & Export
- Export users and expenses into JSON format.
- Download application data as a JSON backup.
- Import previously exported JSON files.
- Validate imported JSON data before restoring it.

### 🎨 User Interface
- Responsive user interface.
- Tailwind CSS styling.
- User-friendly navigation.
- Simple and intuitive expense management.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling |

| Tailwind CSS | Responsive UI design |
| JSON | Data import and export |
